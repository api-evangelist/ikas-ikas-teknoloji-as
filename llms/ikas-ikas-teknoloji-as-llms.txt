# ikas (IKAS Teknoloji AS)

> ikas is an all-in-one e-commerce platform (backed by 500 Global) with a public
> GraphQL Admin API for managing products, orders, customers, inventory,
> campaigns, sales channels, storefronts, and webhooks. Apps authenticate with
> OAuth 2.0 and scoped permissions. This file is generated by the API Evangelist
> enrichment pipeline from the ikas developer documentation.

## API
- ikas Admin API (GraphQL): https://api.myikas.com/api/v1/admin/graphql
- Getting started / auth: https://ikas.dev/docs/api/getting-started/authentication
- API reference (products): https://ikas.dev/docs/api/admin-api/products
- Webhooks: https://ikas.dev/docs/api/admin-api/webhooks
- GraphQL playground: https://ikas.dev/playground

## Auth
- OAuth 2.0; client_credentials (private apps) and authorization_code (public admin apps)
- Token URL: https://{store_name}.myikas.com/api/admin/oauth/token
- Bearer access tokens, expires_in 14400 seconds
- Scopes: read_products/write_products, read_orders/write_orders, read_customers/write_customers, read_campaigns/write_campaigns, read_inventories/write_inventories
